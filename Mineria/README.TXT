PROJECT TITLE: Gestor de Riesgos - Mina (MVC en Java/BlueJ)
PURPOSE OF PROJECT: Juego serio para registrar y consultar riesgos de una mina subterranea.
HOW TO START THIS PROJECT: Clic derecho sobre la clase Main -> void main(String[] args)
STRUCTURE: paquete modelo (Riesgo, GestorRiesgos), paquete vista (JFGestion), paquete controlador (Control), Main.
